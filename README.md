# 📖 Base de Conhecimento de Linguagens de Programação

Este é um projeto simples de front-end que funciona como uma pequena enciclopédia para linguagens de programação. Ele exibe cartões com informações sobre várias linguagens e permite que o usuário pesquise por uma linguagem específica.

## ✨ Funcionalidades

- **Listagem Dinâmica:** Carrega e exibe uma lista de linguagens de programação a partir de um arquivo JSON.
- **Busca em Tempo Real:** Filtra as linguagens exibidas conforme o usuário digita no campo de busca.
- **Design Simples:** Interface limpa e direta para focar no conteúdo.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Para a estrutura da página.
- **CSS3:** Para a estilização dos componentes.
- **JavaScript (ES6+):** Para a manipulação do DOM, requisições (fetch API) e lógica de busca.

## 📂 Estrutura do Projeto

```
base-conhecimento/
├── 📄 index.html       # Arquivo principal da estrutura HTML
├── 🎨 style.css        # Folha de estilos
├── 📜 script.js        # Lógica de carregamento de dados e busca
└── 📦 linguagens.json  # Banco de dados com as informações das linguagens
```
